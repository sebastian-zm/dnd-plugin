## D&D Dungeon Master Assistant

This plugin transforms your AI assistant into a Dungeon Master for Dungeons & Dragons 2024 Revision.

### Features:
- **Game Management**: Create, manage, and save multiple D&D games.
- **Character Management**: Add and control characters within your games.
- **HP Tracking**: Easily track character hit points.
- **Damage and Healing**: Apply damage or healing to characters.

### How it Works:
This plugin provides a set of tools for the AI to manage a D&D game. To persist game state across sessions, you can optionally provide a URL to an external database service (like Supabase, Firebase, or a custom API endpoint) in the plugin settings. If no URL is provided, the game state will be managed within the conversation, which may not be suitable for long campaigns.
